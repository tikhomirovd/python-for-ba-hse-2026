## На лекции

- HTTP: методы, коды ответов, заголовки. Что делать с 4xx и 5xx
- JSON и XML; `requests` / `httpx`
- Пагинация: offset, cursor, «пока не пусто»
- Аутентификация: ключи, токены, OAuth. Где хранить и что делать при утечке
- Тайм-ауты, retry с задержкой, ограничения частоты, идемпотентность
- Парсинг HTML; правовые и этические ограничения сбора данных

## На семинаре

- Забор данных СберИндекса, курсов Банка России (XML) и котировок Мосбиржи (JSON с пагинацией)
