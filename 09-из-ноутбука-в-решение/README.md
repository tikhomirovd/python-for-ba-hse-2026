# 09. От разведочного ноутбука к аналитическому решению: пакет, конфигурация, запуск по расписанию

> **Проверочная работа № 3** — в начале лекции, 10 минут, по темам 07–08: постановка пилота, выбор экспериментальной единицы и метрик, интерпретация результата эксперимента, типовые ошибки анализа.

## На лекции

- Почему ноутбук нельзя эксплуатировать: порядок ячеек, скрытое состояние, невоспроизводимость, невозможность ревью
- Модули и пакеты, структура репозитория, разделение слоёв: загрузка / преобразование / расчёт метрик / доставка
- Конфигурация и работа с секретами; **почему пароль от базы в коде — это инцидент**, а не мелочь
- Журналирование вместо печати
- Интерфейс командной строки, фиксация зависимостей
- Запуск расчёта по расписанию средствами планировщика и облачного сервиса
- Поведение при сбое, повторный запуск и восстановление

## На семинаре

- Практикум: перевести собственный расчёт первого модуля в пакет с интерфейсом командной строки и поставить его на расписание

## Задание

На этой лекции проходит формальный разбор задания **итогового проекта** (экзамен). Само задание опубликовано 07.11, чтобы на работу был месяц.
Сдача — **06.12**, защита — **09.12** (гр. А) / **12.12** (гр. Б).
