## На лекции

**Лекция идёт практикумом, без слайдов.** Вы приходите с ноутбуком: главные строки я пишу на экране, остальное берём готовым и разбираем, вы повторяете у себя.
За пару разведочный ноутбук превращается в маленькую систему: модуль с расчётом, команда
`uv run prime report --date`, настройки в `.env`, журнал, повторный прогон по дням без дублей и расписание.
У каждого шага есть готовое состояние в репозитории, поэтому отставший догоняет одной командой.
Данные — снимок прямо в репозитории: сеть и учебный сервер на паре не нужны.

Что разбираем по ходу:

- Почему ноутбук нельзя эксплуатировать: порядок ячеек, скрытое состояние, невоспроизводимость, невозможность ревью
- Модули и пакеты, структура репозитория, разделение слоёв: загрузка / преобразование / расчёт метрик / доставка
- Конфигурация и работа с секретами; **почему пароль от базы в коде — это инцидент**, а не мелочь
- Журналирование вместо печати
- Интерфейс командной строки, фиксация зависимостей
- Запуск расчёта по расписанию средствами планировщика и облачного сервиса
- Поведение при сбое, повторный запуск и восстановление

## Что подготовить заранее

К **лекции** — ноутбук с заряженной батареей и репозиторий практикума, склонированный дома. В аудитории
пакеты качать не придётся:

```bash
git clone https://github.com/tikhomirovd/prime-l9-workshop.git
cd prime-l9-workshop
uv sync
uv run python -c "import pandas, prime; print('готово, pandas', pandas.__version__)"
```

Последняя команда должна напечатать `готово, pandas 3.0.5`. Если `uv sync` упал или ничего не напечаталось —
напишите в чат курса до пары, а не в аудитории. Открывать ноутбук будем в VS Code или через
`uv run jupyter lab` — подойдёт то, чем вы пользуетесь обычно.

Пара начинается с проверочной работы по темам 07–08, поэтому повторите их: слайды Л7 и Л8, ноутбуки С7 и С8.

К **семинару** — репозиторий своей команды итогового проекта, склонированный у каждого, и ноутбук
