## На лекции

**Лекция идёт практикумом, без слайдов, и делится на две половины.**

В первой вы повторяете у себя на ноутбуке. Собираем загрузчик из двух открытых API — курсы валют Банка России
и история индекса Мосбиржи. У каждого шага есть готовое состояние в репозитории, поэтому отставший догоняет
одной командой. Если в аудитории не будет сети, программа работает на записанных заранее ответах.

Во второй смотрим на экран: как Python разговаривает с базой данных и почему один и тот же расчёт
в колоночном хранилище идёт в десятки раз быстрее. Эти числа сняты заранее, повторять их не нужно.

**Внешние источники** — первая половина, руками

- Протокол HTTP и коды ответов; форматы JSON и XML
- Выполнение запросов из Python, постраничное получение данных
- Аутентификация: ключи, токены, OAuth — где хранить, как ротировать, что делать при утечке
- Ограничения частоты запросов, тайм-ауты, повторные попытки, идемпотентность обращения
- Правовые и этические ограничения сбора данных

**Хранилища** — вторая половина, с экрана

- Подключение к базе данных из Python, параметризованный вызов запроса
- Выгрузка результата порциями и контроль потребления памяти
- Соответствие типов на границе базы данных и `DataFrame`
- Сопоставление реляционного и колоночного хранилищ на одной задаче и причины различия в производительности
- Обзорно: файловые форматы и партиционирование, альтернативные библиотеки обработки данных и критерии их выбора

## Что подготовить заранее

К **лекции** — тот же ноутбук, что на Л9 (пары идут подряд), и второй репозиторий практикума,
склонированный дома. В аудитории пакеты качать не придётся:

```bash
git clone https://github.com/tikhomirovd/prime-l10-workshop.git
cd prime-l10-workshop
cp .env.example .env
uv sync
uv run prime check
```

Последняя команда должна напечатать версии и две строки «отвечает»:

```text
Python 3.12.13, pandas 3.1.1, requests 2.34.2
ЦБ РФ: отвечает, код 200
Мосбиржа: отвечает, код 200
```

Версии могут быть чуть другими. В PowerShell `cp` тоже работает. Если `uv sync` упал — напишите в чат курса
до пары, а не в аудитории. Если дома сайт ЦБ или Мосбиржи не отвечает — тоже напишите: на паре
включим офлайн-режим, но лучше знать заранее.

К **семинару** — репозиторий своей команды итогового проекта, склонированный у каждого.
