## На лекции

**Внешние источники**

- Протокол HTTP и коды ответов; форматы JSON и XML
- Выполнение запросов из Python, постраничное получение данных
- Аутентификация: ключи, токены, OAuth — где хранить, как ротировать, что делать при утечке
- Ограничения частоты запросов, тайм-ауты, повторные попытки, идемпотентность обращения
- Правовые и этические ограничения сбора данных

**Хранилища**

- Подключение к базе данных из Python, параметризованный вызов запроса
- Выгрузка результата порциями и контроль потребления памяти
- Соответствие типов на границе базы данных и `DataFrame`
- Сопоставление реляционного и колоночного хранилищ на одной задаче и причины различия в производительности
- Обзорно: файловые форматы и партиционирование, альтернативные библиотеки обработки данных и критерии их выбора

## На семинаре

- Практикум: сборка загрузчика данных из открытого API — курсы валют, биржевые котировки, статистика потребительских расходов
- Получение одной и той же витрины из реляционного и колоночного хранилищ со сравнением времени и памяти
