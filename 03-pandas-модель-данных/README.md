## На лекции

- Объекты `Series`, `DataFrame` и `Index` — что такое индекс и почему он всё время мешает
- Система типов: категориальные и временные типы, типы с поддержкой пропусков; влияние на корректность и потребление памяти
- Чтение данных из CSV, Excel, JSON, Parquet и из базы данных. Excel и Parquet — обзорно: в окружении курса нет нужных для них библиотек, их вы ставите сами — в `main` своего `prime-monitor` командой `uv add pyarrow openpyxl`; к файловым форматам вернёмся в теме 10
- Отбор по меткам, позициям и булевым маскам; векторизованные операции против поэлементных циклов
- Пропуски, дубликаты, приведение типов
- Приёмка таблицы: семь вопросов, которые задают любой таблице до того, как что-то по ней считать

> Курс читается на **pandas 3.x**. Copy-on-Write включён всегда, `SettingWithCopyWarning` из API удалён: запись в срез молча не доходит до исходного кадра, и предупреждения об этом больше не будет. Учебники и статьи, написанные до pandas 3.0, в этом месте вводят в заблуждение.

## На семинаре

- Добор по git: ветка, коммит, push и pull request — для тех, у кого после лекции это ещё не работает
- Приёмка таблицы: семь вопросов с лекции — по вашей таблице из `prime.assignments`
- Практикум: аудит сырых данных ПРАЙМ — пропуски в канале привлечения, сессии, которые кончаются раньше, чем начались, нулевые и отрицательные суммы, двойные списания
- Приведение типов и замер памяти до и после; построение цепочек преобразований
- Найденные проверки переезжают в код — файл `src/prime/checks.py` в вашем репозитории

Здесь проверки разовые: пишутся руками и запускаются по сырой таблице. Проверки, которые работают сами и каждый день, — тема 11.
