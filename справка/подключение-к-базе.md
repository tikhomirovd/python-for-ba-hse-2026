# Подключение к учебной базе ПРАЙМ

Учебные данные лежат в PostgreSQL на сервере курса. У каждого свой логин и пароль.

---

## 1. Получить доступ

Напишите боту курса [t.me/hse_python_2627_bot](https://t.me/hse_python_2627_bot) команду **`/db`**. Он пришлёт готовую строку подключения — с вашим логином и паролем внутри.

Доступ выдаётся только зарегистрированным в боте. Если бот вас не знает — сначала `/start`.

## 2. Положить её в `.env`

В корне репозитория курса (там, где лежит `README.md`) есть файл `.env.example`. Скопируйте его:

```bash
cp .env.example .env
```

На Windows в PowerShell:

```powershell
copy .env.example .env
```

Откройте `.env` и замените строку `PRIME_DSN=...` на ту, что прислал бот. Должно получиться так:

```
PRIME_DSN=postgresql+psycopg://ivanov_i:xxxxxxxxxxxxxx@2.56.240.205:5432/prime?sslmode=require
```

Всё в одну строку, без пробелов вокруг `=`, без кавычек.

> **Почему в файл, а не в код.** Ноутбук вы покажете преподавателю, выложите на GitHub, отправите однокурснику — пароль поедет вместе с ним. `.env` закрыт в `.gitignore` и не уедет никуда. В ДЗ-1 за это стоит 1,5 балла отдельным критерием.

## 3. Проверить

```bash
uv run python -c "
import os
from dotenv import load_dotenv
from sqlalchemy import create_engine, text
load_dotenv()
with create_engine(os.environ['PRIME_DSN']).connect() as c:
    print(c.execute(text('select current_user, count(*) from prime.payments')).one())
"
```

Ожидаемый ответ — ваш логин и число `3147409`:

```
('ivanov_i', 3147409)
```

Получилось — вы готовы к семинару.

## Что вам можно в базе

| | |
|---|---|
| Схема `prime` | **только чтение.** База одна на всех, испортить общие данные нельзя |
| Схема `student_<ваш логин>` | **ваша целиком.** Создавайте таблицы, складывайте промежуточные результаты |

Ваша схема стоит первой в `search_path`, поэтому `create table витрина (...)` без префикса создаст таблицу именно в ней. К общим данным обращайтесь с префиксом: `prime.payments`.

Ограничения, о которых стоит знать заранее:

* запрос дольше **2 минут** сервер обрывает — это защита от `select * from prime.service_usage` на восьми миллионах строк;
* открытая транзакция без активности закрывается через 5 минут;
* временные файлы одного запроса — до 2 ГБ.

Ни одно из них не мешает работать нормально. Все три срабатывают ровно тогда, когда запрос написан не так.

## Если не подключается

### `connection timed out` · `Operation timed out` · подключение висит

Ваша сеть режет порт 5432. Так делают многие корпоративные сети и часть VPN.

**Замените в `.env` `:5432` на `:443`** и попробуйте снова. Это тот же самый сервер — у него снаружи открыты два входа, и 443 не закрывают нигде, потому что на нём стоит весь https.

Если и это не помогло — выключите VPN и попробуйте с мобильного интернета. Так вы отделите «не работает сервер» от «не пускает моя сеть».

### `password authentication failed for user ...`

Опечатка в логине или пароле. Копируйте строку из бота **целиком**, одним куском, а не собирайте по частям. Пароль состоит из букв и цифр, в нём нет спецсимволов — если вы видите в своей строке что-то ещё, значит, потерялся кусок адреса.

### `No module named 'psycopg'` · `No module named 'dotenv'`

Ноутбук или скрипт запущен не тем Python. Проверьте:

```bash
uv sync
```

В JupyterLab и VS Code ядро должно быть `.venv` этого проекта, а не системный Python. В VS Code — кнопка **Select Kernel** справа сверху, см. [памятку](vscode.md).

### `could not translate host name`

При копировании потерялась часть адреса. Сверьте с `.env.example`.

### `permission denied for table ...`

Вы пытаетесь писать в общую схему `prime`. Так и задумано. Пишите в свою: без префикса или явно `student_<ваш логин>.имя_таблицы`.

### `relation "payments" does not exist`

Забыт префикс схемы. Нужно `prime.payments`.

### `canceling statement due to statement timeout`

Запрос шёл дольше двух минут. Почти всегда это `select *` по большой таблице. Спросите у базы результат, а не сырьё: `count(*)`, `group by`, `limit`.

## Если ничего не помогло

Напишите в чат курса и приложите **текст ошибки целиком** плюс: вашу ОС, порт из `.env` (5432 или 443), сеть (дом, ВШЭ, мобильный, VPN). Без этого помочь нельзя — по «не подключается» диагноз не ставится.

Свой пароль в чат не отправляйте. Никогда и никому, включая преподавателя.
