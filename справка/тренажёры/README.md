# Тренажёры

Место, где можно набить руку вне занятий. Ничего отсюда не сдаётся и не оценивается — это тренировка.

Курс идёт быстро, и полутора парами в неделю беглость не ставится. Ставится она повторением, поэтому здесь собрано то, что можно делать по двадцать минут в день.

## Наш тренажёр

**[Python: коллекции и функции](python-коллекции-и-функции.ipynb)** — 14 задач на данных ПРАЙМ: списки, словари, множества, генераторы, функции, исключения.

Проверка встроена: она знает правильный ответ, но не показывает его — эталоны лежат хешами. Замените `None` на своё решение и запустите ячейку.

Задачи ровно тех типов, что будут в ДЗ-1, где за них стоит 3 балла из 10.

```bash
cd python-for-business-analytics
git pull
uv run jupyter lab
```

## Если Python видите впервые

Начинать с задач в этом случае бессмысленно — сначала нужен сам язык.

- **[«Поколение Python»: курс для начинающих](https://stepik.org/course/58852/promo)** (Stepik, на русском, бесплатно) — самый прямой путь с нуля. Автопроверка, объяснения, никакого предварительного знания не требует.
- **[Python Tutor](https://pythontutor.com/)** — показывает, что происходит в памяти на каждом шаге программы. Именно здесь становится видно, почему `b = a` не делает копию: на схеме две стрелки указывают на один список. Если разделы 6 семинарского ноутбука не сложились в голове — идите сюда.

## Задачи на каждый день

- **[Practice Python](https://www.practicepython.org/)** — 36 маленьких задач по нарастающей, с разборами. Хорошо ложится на «двадцать минут перед сном».
- **[CheckiO](https://checkio.org/)** — задачи в виде игры, после решения показывают чужие решения той же задачи. Второе полезнее первого: там видно, как то же самое пишут короче.
- **[Codewars](https://www.codewars.com/)** — то же в формате рейтинга, задач очень много.
- **[HackerRank: Python](https://www.hackerrank.com/domains/python)** — ближе всего к техническим собеседованиям, если это ваша цель.

Дополнительно — **[раздел про структуры данных в официальном учебнике Python](https://docs.python.org/3/tutorial/datastructures.html)**. Это не тренажёр, а справочник, но по спискам, словарям и множествам он короткий и исчерпывающий.

## Git

- **[Git Exercises](https://gitexercises.fracz.com/exercise/master)** — настоящий репозиторий, задачи проверяются командой `git verify`. **Первые одиннадцать, до `fix-typo` включительно** — то, что нужно для курса; дальше по желанию.
- **[Learn Git Branching](https://learngitbranching.js.org/?locale=ru_RU)** — ветки и слияния в виде анимированного графа, интерфейс на русском. Если после семинара осталось ощущение «я набрал команды, но не понял, что произошло», — это лечится здесь за час.
- **[Pro Git](https://git-scm.com/book/ru/v2)** — книга на русском, бесплатно. Не для чтения подряд: глава 3 про ветвление отвечает почти на все вопросы, которые возникают в первый месяц.

## pandas

Формально это материал темы 03 — лекция 19 сентября. Если хочется забежать вперёд, забегайте: хуже не будет.

- **[Kaggle Learn: Pandas](https://www.kaggle.com/learn/pandas)** — четыре часа, автопроверка, всё в браузере, ставить ничего не нужно.

> **Одна оговорка, и она существенная.** Курс читается на **pandas 3.x**, а почти все внешние материалы — включая этот — написаны для 2.x. Расхождения не косметические: в 3.x всегда включён Copy-on-Write, `SettingWithCopyWarning` удалён из API, строковая колонка по умолчанию имеет тип `str`, а не `object`. Код из чужих тренажёров может вести себя иначе, чем у вас. Это не повод их не проходить — это повод проверять результат, а не верить исходнику.

Раздел пополнится своими задачами на данных ПРАЙМ к теме 03.
