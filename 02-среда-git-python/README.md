- Что недопустимо помещать в репозиторий: данные, пароли, `.env`, чекпоинты ноутбуков
- Чтение сообщений об ошибках и отладка
## На семинаре

- Свой репозиторий проекта из [шаблона](https://github.com/tikhomirovd/prime-monitor-template): клон, ветка, изменение, pull request, разрешение конфликта
- Повторение и систематизация Python: коллекции, генераторные выражения, распаковка, функции, исключения, аннотации типов
- Постановка ДЗ-1

Материалы пары — два файла, они открываются рядом:

- [`С2-git-практикум.md`](семинар/С2-git-практикум.md) — то, что делается в терминале

## Что подготовить заранее

К **лекции** — ничего. К **семинару** — установленные Python 3.12+, [uv](https://docs.astral.sh/uv/) и Git, а также аккаунт на GitHub и регистрация в [боте курса](https://t.me/hse_python_2627_bot).

На этом семинаре мы делаем pull request, а значит, отправляем код на GitHub — для этого нужен **SSH-ключ**. Настраивается он на семинаре темы 01, который идёт первой парой того же дня; инструкция — [«Git и GitHub»](../справка/git-и-github.md). Если сделаете заранее, семинар начнётся сразу с дела.

Чек-лист и проверка окружения — [«Что должно быть готово к первому семинару»](../справка/к-семинару.md). Пошаговые инструкции: [Windows](../справка/установка-windows.md) · [macOS](../справка/установка-macos.md). Python отдельно ставить не нужно — его поставит uv, и уже установленные у вас версии он не тронет.

Git не ставится слушанием лекции. Очень советую пройти тренажёр [Git Exercises](https://gitexercises.fracz.com/exercise/master) — настоящий репозиторий, задачи проверяются автоматически командой `git verify`. **Первые одиннадцать задач, до `fix-typo` включительно**, стоит сделать до семинара; дальше — по желанию. Другие тренажёры — на [странице тренажёров](../справка/тренажёры/).
