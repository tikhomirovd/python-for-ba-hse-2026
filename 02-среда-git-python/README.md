## На лекции

- Виртуальные окружения и управление зависимостями (uv), структура проекта, JupyterLab и IDE
- Воспроизводимость: `pyproject.toml` против lock-файла, почему в репозиторий идут оба
- Скрытое состояние ноутбука и почему расчёт «сходится только у вас»
- Git и GitHub: коммиты, ветки, pull request, разрешение конфликтов
- Что недопустимо помещать в репозиторий: данные, пароли, `.env`, чекпоинты ноутбуков
- Чтение сообщений об ошибках и отладка
## На семинаре

- Практикум на общем репозитории: клон, ветка, изменение, pull request, разрешение конфликта
- Повторение и систематизация Python: коллекции, генераторные выражения, распаковка, функции, исключения, аннотации типов
- Постановка ДЗ-1

Выдача — **12.09**, дедлайн — **19.09**, 23:59. Срок общий для обеих групп: задание выдаётся, когда семинар прошёл и у А, и у Б. Приём со снижением балла — до 26.09.

## Что подготовить заранее

К **лекции** — ничего. К **семинару** — установленные Python 3.12+, [uv](https://docs.astral.sh/uv/) и Git, а также аккаунт на GitHub и регистрация в [боте курса](https://t.me/hse_python_2627_bot).

Чек-лист и проверка окружения — [«Что должно быть готово к первому семинару»](../справка/к-семинару.md). Пошаговые инструкции: [Windows](../справка/установка-windows.md) · [macOS](../справка/установка-macos.md). Python отдельно ставить не нужно — его поставит uv, и уже установленные у вас версии он не тронет.

Git не ставится слушанием лекции. Очень советую пройти тренажёр [Git Exercises](https://gitexercises.fracz.com/exercise/master) — настоящий репозиторий, задачи проверяются автоматически командой `git verify`. **Первые одиннадцать задач, до `fix-typo` включительно**, стоит сделать до семинара; дальше — по желанию.
