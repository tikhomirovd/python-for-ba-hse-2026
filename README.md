## О чём курс

Это не курс «изучаем pandas». Это курс о том, как аналитик доводит задачу до конца: получает данные, считает метрику, объясняет её бизнесу — и превращает разовый расчёт в решение, которое работает само.

Весь семестр вы собираете **один продукт** — систему мониторинга экосистемной подписки. Каждый семинар добавляет к ней работающий компонент: подключение к базе, витрину данных, расчёт метрик, проверки качества, загрузку из внешних API, бота с алертами, дашборд, запуск по расписанию. К декабрю у вас есть не набор ноутбуков, а работающая система, которую не стыдно показать на собеседовании.

Статистику и методы исследования читает НИС «Методы анализа данных», проектирование баз данных и SQL — «SQL и базы данных». Здесь этого нет: мы занимаемся тем, что происходит между ними.

## Правила курса

**Аудиторные тесты** пишутся без компьютера, без интернета и без ИИ-ассистентов. Они проводятся на лекциях, одновременно для обеих групп.

**Домашние задания и проекты** можно делать с ИИ-ассистентами — это часть профессиональных навыков, и мы отдельно разбираем, как ими пользоваться (тема 12). Но:

- к каждой сдаче прикладывается **декларация**: какой инструмент, для чего, какие существенные подсказки давали;
- на защите вам будут задавать вопросы **по вашему коду**: почему здесь именно такое соединение, что сломается, если убрать вот эту строку;
- **неспособность объяснить собственную работу приравнивается к её невыполнению** независимо от того, насколько хорошо она сделана.

Это не про недоверие. Инструмент, которым вы не можете проверить результат, делает вас слабее, а не сильнее — и на работе это выяснится дороже, чем здесь.

**Учётные данные** доступа к учебному серверу нельзя передавать третьим лицам и отправлять в сторонние сервисы, включая ИИ-ассистентов.

## Как начать

Понадобятся Python 3.12+, [uv](https://docs.astral.sh/uv/), Git и аккаунт на GitHub.

```bash
git clone <адрес этого репозитория>
cd python-for-business-analytics
uv sync
uv run jupyter lab
```

Доступ к учебной базе данных выдаётся на первом семинаре. Пароль хранится в файле `.env` и **никогда** не коммитится — почему именно так, разбираем в теме 07.
